# 🛒 Amazon Sales Analysis & Interactive Dashboard | Excel

An advanced Microsoft Excel project focused on analysing Amazon sales performance through interactive dashboards, business intelligence, statistical analysis, and data visualisation.

The project transforms raw sales data into meaningful business insights using Excel formulas, dynamic filtering, KPI tracking, and interactive reporting.

## 📊 Project Overview

This project analyses an Amazon sales dataset containing 120 orders across different product categories, regions, months, and payment methods.

The primary objective is to understand sales performance, profitability, customer purchasing patterns, and business trends through an interactive Excel dashboard.

## 🎯 Project Objectives

- Analyse overall sales and profitability.
- Identify high-performing product categories.
- Compare sales performance across geographical regions.
- Understand monthly revenue and profit trends.
- Analyse payment method distribution.
- Calculate important business performance indicators.
- Build an interactive dashboard for business decision-making.

## 📁 Workbook Structure

The Excel workbook contains six worksheets:

| Worksheet | Description |
|---|---|
| Dashboard | Overall sales performance and KPI summary |
| Interactive Dashboard | Dynamic dashboard with multiple dropdown filters |
| Raw Data | Original dataset containing 120 sales records |
| Statistical Analysis | Descriptive statistical calculations |
| Pivot Tables | Formula-driven business data summaries |
| Charts | Visual analysis and graphical representation |

## ⚡ Key Dashboard Features

### 1. Interactive Filters

The interactive dashboard includes four dropdown filters:

- Category Filter
- Region Filter
- Month Filter
- Payment Method Filter

Users can select individual values or choose ALL to analyse the complete dataset.

### 2. Key Performance Indicators (KPIs)

The dashboard tracks six important business metrics:

- Total Revenue
- Total Profit
- Total Orders
- Average Order Value (AOV)
- Profit Margin %
- Average Units per Order

### 3. Category Performance Analysis

Compare product categories based on:

- Number of Orders
- Total Revenue
- Total Profit
- Profit Margin
- Average Revenue

### 4. Regional Performance Analysis

Analyse sales performance across five regions:

- North
- South
- East
- West
- Central

### 5. Monthly Sales Analysis

Track business performance across all 12 months using:

- Monthly Revenue
- Monthly Profit
- Monthly Orders
- Monthly Profit Margin

## 🚀 How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Navigate to the Interactive Dashboard worksheet.
4. Use the dropdown filters to select a category, region, month, or payment method.
5. Select ALL to view the complete sales performance.
6. Explore the statistical analysis, pivot tables, and charts worksheets.

**Note:** Microsoft Excel desktop is recommended for the best interactive experience. Some formulas and dropdown features may behave differently in other spreadsheet applications.
